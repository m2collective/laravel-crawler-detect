## Installation

This package can be deployed automatically using Composer:

```
composer require m2collective/laravel-crawler-detect
```

```sh
php artisan crawler-detect:publish-config
```

```bladehtml
@isCrawler

@elseIsCrawler

@endIsCrawler
```
